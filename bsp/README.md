# BSP

Здесь сохранены исходники начального этапа поддержки SD5113. Драйверы, DTS и пакеты, из которых собирается RC12, перечислены в [карте исходников](../README.md#где-лежат-исходники-rc12).

This directory preserves the early SD5113 board support code. For the drivers, device trees, and packages used to build RC12, see the [RC12 source map](../README.en.md#where-to-find-the-rc12-sources).
