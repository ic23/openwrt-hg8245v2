# OpenWrt для Huawei EchoLife HG8245V2

**Русский** · [English](README.en.md)

## ⚠️ RC12 — ЭКСПЕРИМЕНТАЛЬНАЯ ВЕРСИЯ

> [!WARNING]
> **Если вы не знаете, как самостоятельно восстановить HG8245V2 через UART и U-Boot, не скачивайте и не устанавливайте эти образы.** На плате один системный слот. При сбое записи устройство может перестать загружаться, и LuCI окажется недоступен. До первой записи в NOR сохраните полный заводской дамп именно своей платы и убедитесь, что можете остановить U-Boot и загрузить recovery по TFTP. [Инструкция по резервному копированию и установке](validation/hg8245v2-rc12.md)

## Для какой платы и микросхем собран RC12

**Huawei EchoLife HG8245V2, board 1 / PCB 3**, заводская прошивка Huawei `V100R003C00SPC106B176`, U-Boot 1.1.4. Порт основан на OpenWrt 24.10.8 и Linux 6.6.144. Установка проверена на одном экземпляре с NOR 16 МиБ. При выборе образа важны ревизия платы и состав компонентов. Другие ревизии HG8245V2 требуют отдельной проверки и, при другом наборе микросхем, доработки драйверов.

| Узел | Микросхема в проверенной конфигурации | Что работает |
| --- | --- | --- |
| Процессор | **HiSilicon SD5113**, ARM1176JZF-S (ARMv6) | RC12 загружается из NOR. U-Boot видит 64 МиБ RAM, ядру переданы 50 МиБ. |
| Wi-Fi 2,4 ГГц | **Atheros AR9227** по данным владельца платы. Драйвер `ath9k` определяет радио как **AR9287 Rev:2**, PCI ID `168c:002d`. | `owl-loader` применяет заводскую калибровку. На этой плате проверены подключение клиента к точке доступа и обмен по локальной сети. [Лог RC12](validation/hg8245v2-rc12-board-boot.txt) |
| Проводной Ethernet | MAC в **SD5113** и внешний гигабитный коммутатор **Atheros AR8316 rev. 1** | Четыре отдельных порта LAN1–LAN4, объединённых по умолчанию в `br-lan`. |
| Контроллер GPON | Блок GPON в **SD5113** | В порте есть обработка PLOAM, агент OMCI и интерфейс `optic` для Ethernet через GEM. На плате прочитан LOS при снятом волокне. Регистрация на действующем OLT и интернет через него ещё не проверены. |
| Оптический приёмопередатчик | **Huawei HPSF2120**, диагностика по I²C | На плате прочитаны идентификатор, оптическая мощность приёма без сигнала и показания датчиков. Драйвер также распознаёт **RTXM167-407**, **RTXM167-407-C10** и другие профили по идентификаторам из заводской прошивки. Аппаратное испытание оптики проведено только с HPSF2120. [Список профилей](validation/hg8245v2-optics.md) |
| Аналоговая телефония | Двухканальный **Le88266DLC** (SLIC) и голосовой DSP **ZSP** в SD5113 | TEL1 и TEL2. На плате проверены звонок, отбой, интерком и двусторонний звук SIP через Ethernet. [Прошивка DSP и профили линий](docs/voice-firmware.md) |
| Flash и USB | Параллельная **CFI NOR x16, 16 МиБ**. Контроллеры **EHCI/OHCI** в SD5113. | На RC12 подтверждены загрузка из NOR и обнаружение USB-накопителя по EHCI с обоими разделами. |

**Порт требует дальнейшей разработки и расширения списка поддерживаемых микросхем.** Оптика испытана с отключённым волокном. Длительного прогона установленной системы под нагрузкой не было, поведение служб и расход памяти через сутки или неделю неизвестны.

**Порт для базового сценария «интернет по GPON, домашняя сеть и телефон» готов ориентировочно на 70–75%.** Установка в NOR, локальная сеть и разговор между реальными абонентами уже работают. Главный открытый вопрос — сможет ли эта плата зарегистрироваться на OLT оператора, получить профиль по OMCI и пропустить абонентский трафик в обе стороны. До первого такого сеанса совместимость с оператором остаётся неизвестной.

## Файлы выпуска RC12 — что скачивать

**Для запуска без установки** скачайте `recovery`. **Для первой установки поверх заводской прошивки** понадобятся `recovery` для резервной копии, затем `installer` и `factory-region` одного выпуска для записи. **Для обновления через LuCI** выберите `sysupgrade` нужного выпуска.

| Файл в каталоге `artifacts/hg8245v2-rc12/` | Что с ним делать |
| --- | --- |
| [hg8245v2-rc12-recovery.bin](artifacts/hg8245v2-rc12/hg8245v2-rc12-recovery.bin) | Загрузите через TFTP из U-Boot. OpenWrt запустится в RAM. Здесь можно проверить оборудование и сохранить на ПК все 16 МиБ заводской NOR перед установкой. |
| [hg8245v2-rc12-installer.bin](artifacts/hg8245v2-rc12/hg8245v2-rc12-installer.bin) | После резервного копирования загрузите этот установщик через TFTP из U-Boot. Он запустится в RAM и примет файл `factory-region` с ПК. Запись начинается по отдельной команде в консоли установщика. |
| [hg8245v2-rc12-factory-region.bin](artifacts/hg8245v2-rc12/hg8245v2-rc12-factory-region.bin) | Содержимое системной области NOR. Раздайте файл по HTTP с ПК для записи из RAM-установщика. Образ охватывает адреса `0x060000–0xADFFFF` включительно. U-Boot и индивидуальные заводские данные лежат за пределами этой области. |
| [hg8245v2-rc12-sysupgrade.bin](artifacts/hg8245v2-rc12/hg8245v2-rc12-sysupgrade.bin) | Для уже установленного совместимого OpenWrt. Загрузите через **LuCI → System → Backup / Flash Firmware → Flash image…**. Чтобы перенести конфигурацию, оставьте включённым **Keep settings**. |
| [SHA256SUMS](artifacts/hg8245v2-rc12/SHA256SUMS) | Контрольные суммы четырёх образов. Если скачали весь комплект, выполните `sha256sum -c SHA256SUMS` из каталога с файлами. |

Перед записью установщик сверяет контрольные суммы загрузчика, разметки и системного образа. Команды для ПК, U-Boot и консоли OpenWrt приведены по порядку в [инструкции установки и обновления](validation/hg8245v2-rc12.md).

## Готовность по подсистемам

В таблице приведена инженерная оценка объёма выполненной работы по каждой функции. Диапазон учитывает, какая часть пути уже реализована, что удалось воспроизвести и сколько ещё предстоит проверить на плате. Разговор между двумя трубками подтверждает весь тракт от одного микрофона до второго динамика. Загрузка драйвера или создание сетевого интерфейса подтверждает только один этап. Аппаратные результаты ранних сборок учитываются полностью в пределах проверенного сценария. Версия и условия проверки указаны рядом.

Для общей оценки локальной части и оптическому WAN дан одинаковый вес. Средняя оценка первых девяти строк (от установки до USB) — около 85%, следующих пяти (от диагностики модуля до интернета через WAN) — около 60%. По серединам диапазонов получается около 73%. Точнее оценить объём оставшейся работы до испытания на OLT затруднительно. QoS, IPTV, BBU и другие дополнительные функции оценены отдельно. Надёжность при круглосуточной эксплуатации пока оценить нельзя.

| IPTV | 35–50% | Включены IGMP-прокси и страница настройки. Получение канала оператора, переключение групп и отдельный multicast GEM на плате не подтверждены. |
| Индикаторы и кнопки | 65–80% | Разводка сопоставлена со стоком, правила LED открыты в UCI, для LAN наблюдалась индикация линка. Полного прогона состояний PON, LOS, WPS, POTS и POWER на RC12 не было. |

| Удалённое управление оператора (TR-069) | 0% | В конфигурации RC12 нет клиента CWMP. Регистрация на ACS и получение через него операторских настроек не проверялись. |
| Длительная работа, расход RAM и восстановление служб | Нет данных | Нет длительных замеров памяти, циклов вызовов, переподключений и нагрузки Ethernet + Wi-Fi + USB. Наличие или отсутствие утечек неизвестно. |

**Что известно о памяти.** При старте RC12 ядро сообщает `41576K/51200K available`. Последняя отметка в опубликованном загрузочном логе — около 245 секунд. Этот снимок не показывает, сколько RAM останется после длительной работы служб. В одной из ранних RAM-сборок наблюдались убийства процессов и kernel panic. Для установленного RC12 пока нет замеров, по которым можно отличить нехватку RAM при пиковой нагрузке от постепенной утечки памяти. [Загрузочный лог RC12](validation/hg8245v2-rc12-board-boot.txt)

Результаты испытаний можно сверить по [отчёту об установке, обновлении и USB](validation/hg8245v2-rc12.md), [проверке LAN и Wi-Fi](validation/hg8245-lan-wifi-luci-test.txt) и [выводу UART с отключённой оптикой](validation/hg8245-gpon-rx.uart.txt). Для отдельных компонентов сохранены [профили оптики `V100R003C00SPC106B176`](validation/hg8245v2-optics.md), [описание голосовой прошивки](docs/voice-firmware.md), [назначение индикаторов](validation/hg8245-front-panel-leds.md) и [разбор BBU](validation/hg8245-bbu.md).

## GPON на волокне

В RC12 сеть `wan` привязана к интерфейсу `optic`. Агент OMCI реализует базовый формат сообщений и профиль одного моста VEIP. На хосте проверены операции с MIB, привязка двух GEM к разным T-CONT, выбор по PCP/DSCP и симметричное преобразование VLAN. [Тест OMCI](tools/test_sd5113_omci.py) · [Тест GEM и приоритетов](tools/test_sd5113_gem_qos.py).

| Этап | Что предстоит подтвердить на реальной линии |
| --- | --- |
| Регистрация | Проверить снятие LOS, приём серийного номера, назначение ONU-ID, ranging и переход в O5. Повторить после обрыва и возврата сигнала. |
| Настройка от OLT | Записать обмен OMCI на назначенном OMCC и сверить T-CONT/Alloc-ID, GEM Port-ID и правила VLAN с профилем абонента на OLT. |
| Интернет через GEM | Подтвердить передачу и приём через назначенный GEM, получение адреса по DHCP или установление PPPoE и выход клиента LAN в интернет. |
| QoS и IPTV | Измерить распределение трафика по GEM под нагрузкой и проверить получение реального IPTV-потока после подписки по IGMP. |

**Границы реализации.** Поддерживается ограниченный профиль VLAN одного моста. Расширенный формат OMCI, отдельный multicast GEM с операторскими ACL и аппаратная настройка весов очередей и shaping в этот профиль не входят. В образ включён `igmpproxy` для маршрутизируемого IPv4 IPTV.

На подключённой линии эти команды показывают состояние регистрации, настроенные GEM, параметры WAN и счётчики Ethernet:

```sh
ubus call hg8245.gpon status
ubus call network.interface.wan status
grep 'optic:' /proc/net/dev
```

## Сборка

Используйте обычного пользователя Linux. Для WSL2 разместите каталог сборки в домашнем каталоге Linux. Скрипт скачивает OpenWrt с проверкой ревизии `0b795ce79e23b553aa184080c390f9ce92a2b6d4` и применяет исходники из этого дерева. На Ubuntu 24.04 установите зависимости:

```sh
sudo apt update
sudo apt install build-essential clang flex bison gawk gcc-multilib g++-multilib gettext git libncurses-dev libssl-dev python3 python3-setuptools rsync swig unzip zlib1g-dev file wget curl ca-certificates device-tree-compiler xz-utils perl libelf-dev
```

В WSL2 перед сборкой выполните `export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin` в текущем терминале. Это исключает пути Windows с пробелами, из-за которых OpenWrt может прервать упаковку файловой системы.

Все четыре образа RC12 можно собрать без заводского дампа. Выполните из корня репозитория:

```sh
HG8245_RELEASE_DIR="$PWD/dist/rc12" bash tools/build-hg8245-factory.sh
(cd dist/rc12 && sha256sum -c SHA256SUMS)
```

Формат контейнера Huawei, контрольные суммы загрузчика и разметки для `V100R003C00SPC106B176` и микрокод голосового DSP входят в репозиторий. Серийный номер, MAC и калибровку Wi-Fi прошивка читает со своего устройства. Перед первой записью в NOR сохраните полный дамп своей платы для восстановления. [Инструкция по установке](validation/hg8245v2-rc12.md)

Если нужен только RAM-образ:

```sh
HG8245_CONFIG="$PWD/openwrt-target/config.sd5113_hg8245.rc12" HG8245_ARTIFACT_DIR="$PWD/dist/ram" bash tools/build-hg8245-ram.sh
```

Драйвер Wi-Fi `ath9k` и драйверы USB EHCI/OHCI берутся из базового дерева OpenWrt и ядра Linux. Параметры конкретной платы задаются в DTS и конфигурации RC12.
- `tools/` — сборка, упаковка, проверка образов и тесты. `firmware_current/tools/` содержит читатель заводской SquashFS. Часть исследовательских тестов ожидает извлечённые модули `V100R003C00SPC106B176`.
- `validation/` — инструкция RC12, результаты аппаратных испытаний и сведения о плате. Сведения о регистрах заводской прошивки и их использовании в RC12 собраны в [справке по Ethernet, таймерам и watchdog](firmware_current/extracted/README.md).
- `artifacts/hg8245v2-rc12/` — проверенные файлы текущего выпуска. Индивидуальные дампы NOR, BoardInfo, резервные копии настроек и калибровки храните отдельно.
