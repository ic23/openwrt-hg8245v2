# Светодиоды HG8245V2 в RC12

Назначения настраиваются в **LuCI → System → LED Configuration** и хранятся в UCI `system`. Исходные правила для платы задаёт [01_leds](../openwrt-target/target/linux/sd5113/base-files/etc/board.d/01_leds). POTS1 и POTS2 используют состояние соответствующей телефонной линии, LOS и PON — состояние оптики, WLAN — активность радио, WPS — состояние сопряжения, USB — состояние USB. Второму каналу PON по умолчанию назначен триггер `none`. Для POWER выбран триггер резервного питания. С физическим BBU он ещё не проверен.

LAN1–LAN4 обслуживает сам AR8316. Физическим гнёздам LAN1–LAN4 соответствуют порты коммутатора 2, 3, 4 и 1. [Сопоставление портов платы](../openwrt-target/target/linux/sd5113/base-files/lib/hg8245/board-info.sh).

## Кнопки

В заводском профиле board 1 / PCB 3 Reset соответствует GPIO34, WLAN — GPIO35, WPS — GPIO12. В выпущенном RC12 дерево устройств объявляет кнопку WPS на GPIO12 с активным низким уровнем, опросом 20 мс и подавлением дребезга 60 мс. Проверка DTS подтверждает привязку WPS; аппаратный результат полного прогона трёх кнопок для RC12 не записан.
