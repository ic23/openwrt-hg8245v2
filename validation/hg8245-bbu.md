# Внешний BBU на Huawei HG8245V2

На плате пользователя установлен четырёхконтактный разъём. Профиль HG8245V2 в заводской прошивке включает мониторинг внешнего блока резервного питания. Программный путь проходит через отдельный UART SD5113. Порядок контактов, напряжение сигналов и наличие силового питания на колодке неизвестны. Данных для изготовления кабеля пока недостаточно.

## Как устроен обмен

- В `etc/wap/HG8245V2/hw_ldsp_cfg.xml` активная запись `BATTERY/Cfg1` с командой `0x2000a000` задаёт Support=1, SendDataTime=10, RecvDataTime=20, ReportTime=3000. В драйвере таймеры используют `msecs_to_jiffies`. Объявленная поддержка означает, что заводское ПО умеет опрашивать блок. Физическое присутствие аккумулятора определяется отдельно.
- `hw_module_battery.ko` очищает очередь приёма и передаёт один байт команды в `hw_drv_battery_send_curr_data` (.text+0x1c4c, +0x1c88). В `hw_drv_battery_recv_data` (.text+0x1db0) драйвер последовательно читает семь байтов. Одна ветвь распознаёт первые два байта на проводе как ASCII `HW` и разбирает младшие тетрады следующих байтов. Есть отдельная ветвь для запроса `A`. Этот формат нельзя распространять на все модели BBU без записи обмена.
- `hw_soc_sd5113.ko`, функция `hw_chip_uart_init` (.text+0x967c), включает UART, выбирает индекс 0 в массиве заводского SDK и скорость с индексом 0. В `hi_uart.ko` отображение начинается с 0x1614e000, второй контроллер расположен на 0x1000 выше. Индекс 0 выбирает делитель AHB/(16 × 9600). Исходные значения длины слова, стопового бита и чётности в `.init.text+0xf0` соответствуют 8N1. Так получаются заводские параметры **9600 8N1**. В дереве OpenWrt этот контроллер назван `uart1`. Консоль U-Boot/Linux использует адрес 0x1614f000.
- При включении этого UART заводская функция выставляет бит 7 по адресу 0x16146008 и бит 0 по адресу 0x16147008. Это мультиплексор GPIO0[7] и GPIO1[0]. Их порядок на колодке и направление TX/RX на контактах прошивка не указывает.
- Заводской интерфейс предоставляет производителя, напряжение, температуру, ёмкость, остаток, токи заряда и разряда, источник питания, число циклов и аварии. Обёртка `/usr/bin/wap.smp.apm.show_battery` в штатной системе запрашивает статус у процесса `apm`.
